# college-expense-tracker
A Java Program to track college expenses

## Project Goal

As a college student, I sometimes lose track of how much money I am spending, especially on food and random purchases. I want to make an expense tracker that helps me keep track of where my money is going.

## MVP Features

- Add purchases with a name, amount and category
- View previous expenses
- Calculate total spending
- See how much money was spent in each category
- Save and load expenses using a CSV file

## Tech Stack

- **Language:** Java
- **Libraries:** Scanner, ArrayList and Java file I/O
- **Data Storage:** CSV File
- **Tools:** VS Code and GitHub

## Future Plans

- Add monthly spending summaries
- Let users set their own spending limits
- Allow users to edit or delete expenses

## Build Plan
1. Set up a GitHub repository and create the Java project in VS Code
2. Create a menu where users can add expenses, view expenses or exit
3. Write the code to let users enter a purchase name, amount and category
4. Use an ArrayList to store expenses and display them when needed
5. Add features to calculate total spending and show how much was spent in each category
6. Save expenses to a CSV file and test program to see everything works
